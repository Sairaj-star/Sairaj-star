### 💎 My UI/UX principles

- 🎯 **Clarity first:** Make interfaces easy to understand.
- ⚡ **Motion with purpose:** Use animation to guide, not distract.
- 🧩 **Reusable by design:** Build consistent and maintainable components.
- ♿ **Accessible experiences:** Design for different users and devices.
- 🔥 **Details matter:** Refine spacing, typography, feedback, and responsiveness.

*These repositories are design references. Their libraries and components are not automatically installed in my projects.*
